# Putnam 1996: maximização de uma soma cíclica

Material visual de Osvaldo L. Santos-Pereira para o problema 56 de *Math Problem Book I*.

## Estado do envio

A estrutura de diretórios foi criada. O envio dos arquivos PNG ao GitHub está pendente. As 25 imagens estão organizadas no pacote `putnam_1996_arquivos_organizados.zip`, entregue na conversa que originou este material. Este README não indica que as imagens já estejam publicadas no repositório.

## Organização preparada

A pasta `16x9/` receberá as sete páginas manuscritas, do enunciado à referência bibliográfica, e a figura complementar aprovada sobre a soma cíclica, sem numeração:

- `01_enunciado.png`
- `02_identidade_quadratica.png`
- `03_soma_dos_quadrados.png`
- `04_desigualdade_auxiliar.png`
- `05_limite_superior.png`
- `06_igualdade_e_resultado.png`
- `07_referencia_bibliografica.png`
- `detalhe_soma_ciclica_sem_numeracao.png`

A pasta `extra/` receberá dez versões alternativas das explicações e sete páginas da primeira versão. Essas imagens são arquivos de produção, não uma sequência didática consolidada.

Os PNGs do pacote foram preservados sem alterações de conteúdo, resolução ou compressão. Foram normalizados apenas os nomes dos arquivos. Duplicatas visuais idênticas, testes de fontes, folhas de contato e arquivos PDF não foram incluídos.

O pacote inclui `manifesto_arquivos.csv`, com os nomes originais, dimensões, tamanhos e resumos SHA-256 das imagens. Sua estrutura interna começa em `matematica/algebra_putnam_1996_soma_ciclica/`, permitindo copiar os arquivos para a raiz de uma cópia local deste repositório.
